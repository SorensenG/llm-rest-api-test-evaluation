# Limitações

O SUT original usa MySQL com placeholders no `application.yml` e não inclui OpenAPI versionado; o repositório agora preserva a captura runtime de `/v3/api-docs`. Há uma divergência conhecida em `POST /api/project`: o contrato documenta 200, mas a execução válida observada retornou 201. Falhas exclusivas dessa diferença serão mantidas como falha de asserção/`erro da API` com subcategoria própria, sem correção automática. A aplicação pode ter bugs e dados persistentes; reset e logs são necessários. Chat interfaces não garantem controle de temperatura, seed ou mudanças internas. A análise de validade, execução e causa de falhas exige revisão humana.
