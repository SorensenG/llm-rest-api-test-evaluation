# Seleção dos modelos

O modelo A é Google Gemini 3.6 Flash (`gemini-3.6-flash`), interface Gemini, 10 repetições. O modelo B é OpenAI GPT-5.6 Luna (`gpt-5.6-luna`), interface ChatGPT Work, 10 repetições.

A seleção compara fornecedores diferentes orientados à eficiência e menor custo relativo. Isso não afirma capacidade equivalente: a equivalência será uma questão empírica. Interfaces de chat não permitem controlar diretamente todos os parâmetros, como temperatura; configurações internas, atualizações e políticas das plataformas podem afetar os resultados. Antes da coleta, confirme manualmente a disponibilidade e seleção exata; não substitua modelo indisponível.
