# Seleção dos modelos

O modelo A é Google Gemini 3.6 Flash (`gemini-3.6-flash`), acessado manualmente pela interface Gemini, com 10 repetições. O modelo B é OpenAI GPT-5.6 Luna (`gpt-5.6-luna`), acessado manualmente pela interface ChatGPT Work, com 10 repetições.

A seleção compara fornecedores diferentes orientados à eficiência e menor custo relativo. Isso não afirma capacidade equivalente: a equivalência será uma questão empírica. Interfaces de chat não permitem controlar diretamente todos os parâmetros, como temperatura, seed, limites de contexto ou políticas de amostragem; configurações internas, atualizações e políticas das plataformas podem afetar os resultados. A disponibilidade efetiva e a seleção exata dos dois identificadores devem ser confirmadas manualmente pelo pesquisador imediatamente antes da coleta. Essa confirmação não é validada automaticamente por esta infraestrutura; não substitua modelo indisponível.
